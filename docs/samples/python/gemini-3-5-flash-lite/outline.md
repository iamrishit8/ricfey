# Practical Python for Everyday Tasks

_Depth: working_

A 4-week practical guide to mastering Python for automation, data handling, and problem solving, tailored for self-paced study.

## Week 1: Core Syntax and Data Types

**Day 1: Setting Up and Printing**  
Topics: `python-setup`, `print-statement`

- Run basic Python commands in an interactive shell
- Print formatted output to the console

**Day 2: Variables and Basic Math**  
Topics: `variables`, `basic-math`

- Store values in variables using descriptive names
- Perform arithmetic operations on numbers

**Day 3: Working with Strings**  
Topics: `strings`, `f-strings`

- Manipulate text using string methods
- Format strings using f-strings

**Day 4: User Input and Type Conversion**  
Topics: `user-input`, `type-conversion`

- Capture input from the user
- Convert data types between strings and numbers

**Day 5: Booleans and Comparisons**  
Topics: `booleans`, `comparisons`

- Evaluate comparison and logical operators
- Store boolean states in variables

## Week 2: Control Flow and Collections

**Day 6: Conditional Statements**  
Topics: `conditionals`, `control-flow`

- Write if-elif-else branches to control execution flow
- Evaluate complex conditions securely

**Day 7: Introduction to Lists**  
Topics: `lists`, `indexing`

- Create and modify lists with items
- Access list elements using positive and negative indexing

**Day 8: For Loops**  
Topics: `for-loops`, `range-function`

- Iterate over items in a list using for loops
- Generate sequences of numbers using the range function

**Day 9: While Loops**  
Topics: `while-loops`, `control-flow`

- Write while loops for condition-based repetition
- Prevent infinite loops using break statements

**Day 10: Dictionaries for Key-Value Data**  
Topics: `dictionaries`, `key-value-pairs`

- Store structured data using dictionaries
- Access and update dictionary values

## Week 3: Functions and Data Processing

**Day 11: Defining Functions**  
Topics: `functions`, `parameters`

- Write reusable code blocks using custom functions
- Pass arguments and return values from functions

**Day 12: Scope and Default Arguments**  
Topics: `variable-scope`, `functions`

- Distinguish between local and global variable scope
- Define functions with default argument values

**Day 13: List Comprehensions**  
Topics: `list-comprehensions`, `lists`

- Write concise list transformations using list comprehensions
- Filter lists efficiently in a single line of code

**Day 14: Error and Exception Handling**  
Topics: `exception-handling`, `debugging`

- Catch runtime errors using try-except blocks
- Handle multiple specific exceptions gracefully

**Day 15: Reading and Writing Text Files**  
Topics: `file-io`, `context-managers`

- Open, read, and write text files using context managers
- Process file contents line by line

## Week 4: Modules, Automation, and Capstone

**Day 16: Using Built-in Modules**  
Topics: `modules`, `standard-library`

- Import and use standard library modules like math and random
- Work with dates and times using the datetime module

**Day 17: Working with CSV Data**  
Topics: `csv-parsing`, `file-io`

- Parse and analyze tabular data from CSV files
- Write processed data back into a CSV format

**Day 18: Building Command Line Arguments**  
Topics: `command-line-args`, `sys-module`

- Accept command line inputs using sys.argv
- Build a small script that takes parameters from the terminal

**Day 19: Writing Clean Code and Tests**  
Topics: `code-style`, `testing`

- Format code using PEP 8 style guidelines
- Write simple assertion tests to verify function correctness

**Day 20: Automation Capstone Project**  
Topics: `capstone-project`, `automation`

- Combine loops, files, and functions into a complete utility script
- Automate a repetitive text-processing task from scratch
