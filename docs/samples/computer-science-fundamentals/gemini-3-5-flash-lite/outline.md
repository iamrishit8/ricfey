# Computer Science Fundamentals for Working Professionals

_Depth: working_

Master the core pillars of computer science—data structures, algorithms, system design basics, and core architecture—to build efficient, scalable software.

## Week 1: Data Structures & Memory

**Day 1: How Computers Store Data: Memory and Variables**  
Topics: `memory-basics`, `stack-vs-heap`

- Explain how RAM stores variables using memory addresses
- Differentiate between stack and heap memory allocation

**Day 2: Arrays and Strings in Memory**  
Topics: `arrays`, `string-memory`

- Calculate memory offsets for contiguous array elements
- Identify performance bottlenecks of string manipulation

**Day 3: Linked Lists: Pointers and Nodes**  
Topics: `linked-lists`, `pointers`

- Draw node references for singly and doubly linked lists
- Compare time complexities of insertions in arrays versus linked lists

**Day 4: Stacks and Queues: LIFO and FIFO**  
Topics: `stacks`, `queues`

- Implement a stack using basic array operations
- Explain real-world queue use cases like task scheduling

**Day 5: Hash Maps and Collision Resolution**  
Topics: `hash-maps`, `collision-resolution`

- Explain how hash functions map keys to indices
- Resolve collisions using chaining and open addressing

## Week 2: Algorithms & Complexity

**Day 6: Introduction to Big O Notation**  
Topics: `big-o`, `time-complexity`

- Calculate time complexity for simple loops
- Differentiate between O(1), O(n), and O(n^2) runtimes

**Day 7: Searching Algorithms: Linear and Binary Search**  
Topics: `binary-search`, `search-algorithms`

- Implement binary search on a sorted dataset
- Determine when to apply binary search over linear search

**Day 8: Basic Sorting: Bubble, Selection, and Insertion Sort**  
Topics: `sorting`, `insertion-sort`

- Trace the state of an array through insertion sort passes
- Compare worst-case efficiencies of basic sorting algorithms

**Day 9: Efficient Sorting: Merge Sort and Quick Sort**  
Topics: `sorting`, `divide-and-conquer`

- Explain the divide-and-conquer strategy in merge sort
- Choose appropriate sorting algorithms based on dataset constraints

**Day 10: Recursion Fundamentals**  
Topics: `recursion`, `call-stack`

- Identify the base case and recursive step in a function
- Trace call stack growth during recursive execution

## Week 3: Databases & Storage

**Day 11: Relational Databases & Normalization**  
Topics: `databases`, `normalization`

- Design normalized tables up to 3rd Normal Form
- Define primary and foreign keys to enforce relationships

**Day 12: SQL Query Optimization & Indexes**  
Topics: `sql`, `indexes`

- Write efficient JOIN queries across multiple tables
- Explain how B-Trees improve database lookup speeds

**Day 13: Transactions and ACID Properties**  
Topics: `transactions`, `acid-properties`

- Explain each letter of the ACID acronym with examples
- Identify scenarios requiring database transaction rollbacks

**Day 14: NoSQL Concepts and Choosing a Database**  
Topics: `nosql`, `database-selection`

- Compare document-oriented storage with relational schemas
- Select between SQL and NoSQL based on application requirements

**Day 15: Caching Strategies**  
Topics: `caching`, `redis`

- Design cache-aside patterns using Redis or Memcached
- Define cache invalidation strategies for frequently updated data

## Week 4: Systems, Networks & Security

**Day 16: How the Web Works: HTTP and DNS**  
Topics: `http`, `dns`

- Trace the DNS lookup process when a URL is entered
- Analyze HTTP request and response status codes

**Day 17: API Design and REST Principles**  
Topics: `api-design`, `rest`

- Design clean RESTful endpoints using proper HTTP verbs
- Structure JSON request and response payloads effectively

**Day 18: Concurrency, Threads, and Processes**  
Topics: `concurrency`, `threads`

- Differentiate between operating system processes and threads
- Identify race conditions in multithreaded environments

**Day 19: Basic Cybersecurity and Authentication**  
Topics: `security`, `authentication`

- Explain token-based authentication using JWT
- Prevent common vulnerabilities like SQL injection and XSS

**Day 20: System Scalability and Load Balancing**  
Topics: `scalability`, `load-balancing`

- Explain horizontal versus vertical scaling strategies
- Describe how load balancers distribute traffic across servers
